# Desk LAN — distribuição oficial

Desk LAN é o novo nome do Prates LAN. [Baixar a versão mais recente](https://github.com/Pr4Tes/desk-lan-releases/releases/latest).

Windows x64 portátil. Baixe DeskLAN-1.4.0-Windows-x64.exe ou extraia o ZIP e abra DeskLAN.exe nos dois PCs da mesma rede local. Atualize os dois PCs para 1.4.0.

Novo nome, ícone e interface com configurações separadas. Perfil, identidade e preferências anteriores preservados. Acesso remoto somente na LAN, com TLS e autenticação. Compartilhamento sempre visível. Sem serviço ou relay na nuvem.

O arquivo técnico PratesLAN-1.4.0-Windows-x64.exe contém os mesmos bytes do DeskLAN e permite compatibilidade com o canal de atualizações assinado anterior. Manifestos, assinaturas e hashes acompanham a release. As versões históricas são preservadas.

79 testes funcionais aprovados com imagens sintéticas e entrada simulada. Teste entre dois PCs físicos permanece pendente. Código-fonte no repositório privado do proprietário; perfis, senhas e chaves privadas não são publicados.
